# IMDB Sentiment Analysis using Deep Learning (NLP)

This project implements an end-to-end deep learning pipeline for sentiment analysis on the IMDB movie reviews dataset. The goal is to classify reviews as positive or negative using modern NLP techniques.

## Features
- Full text preprocessing pipeline (tokenization, sequencing, padding)
- Word embeddings for semantic representation
- Implemented and compared multiple deep learning architectures:
  - LSTM-based model
  - CNN-based text classification model
- Performance evaluation and model comparison

## Tech Stack
- Python
- TensorFlow / Keras
- NLP
- LSTM, CNN
- Embeddings

## Results
The models achieved strong classification performance with good generalization on unseen data.

## Use Case
This project demonstrates practical application of deep learning in NLP and can be extended to:
- Product review analysis
- Social media sentiment analysis
- Opinion mining systems
